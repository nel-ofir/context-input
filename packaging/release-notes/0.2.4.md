# ContextInput 0.2.4 beta

Synthetic layout and regression tests pass. Live conversation validation is
pending; this beta makes the fix available for testing through automatic updates.

- When a context scan is empty, checks complete accessibility children and then
  enclosing containers in the focused window to find sibling message lists.
- Prunes off-column subtrees during fallback so large side panels cannot consume
  its shared scan budget. Existing text-position filters remain in effect.
- Reports fallback scope count in Settings diagnostics.
- Uses element equality instead of hash values alone to identify visited nodes.
- Adds synthetic Hebrew/English window-layout regressions, including empty-chat
  and draft-priority controls. The language classifier is unchanged.
