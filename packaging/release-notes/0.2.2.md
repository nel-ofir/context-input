# ContextInput 0.2.2 beta

This release improves language selection in conversations that contain large
attachments or document previews.

- Prioritizes a confident cluster of the ten nearest text items before consulting
  older visible context.
- Fixes Hebrew Slack conversations being diluted by older English resumes,
  attachments, link previews, and surrounding interface labels.
- Keeps the wider 32-item context as a fallback when the nearest items are mixed.
- Adds mirrored Hebrew and English regression coverage for the new behavior.
