# ContextInput 0.2.2 beta

This release improves language selection in conversations that contain large
attachments or document previews.

- Prioritizes a confident cluster of the ten nearest text items before consulting
  older visible context.
- Fixes Hebrew Slack conversations being diluted by older English resumes,
  attachments, link previews, and surrounding interface labels.
- Keeps the wider 32-item context as a fallback when the nearest items are mixed.
- Prevents business and messaging apps from entering the opaque-terminal fallback
  merely because their bundle advertises a shell-file handler.
- Rejects text that only touches the focused composer's horizontal column by a few
  pixels, preventing adjacent Slack sidebar entries from becoming chat evidence.
- Ignores Slack's paused-notifications status banner, including the fragments
  Electron exposes as separate accessibility text nodes.
- Reduces Slack's duplicated parent message labels to the message body, removing
  English sender names and AM/PM metadata from Hebrew replies.
- Adds mirrored Hebrew and English regression coverage for the new behavior.
