# ContextInput 0.2.0 beta

- Adds automatic, cryptographically signed updates through Sparkle and GitHub Releases.
- Adds **Check for Updates…** to the menu-bar menu and Settings.
- Uses a stable beta code-signing identity so Accessibility approval can survive in-place beta updates.
- Includes the previously tested ChatGPT, WhatsApp, URL-field, terminal-detection, version-display, and Command-W fixes.
- Removes the unsuccessful Warp input-source workarounds. Warp remains a documented compatibility limitation.
